# Decompilation Knowledge Base: mssb-dtk

This document summarizes the core patterns, compiler behaviors, and tooling insights gathered during the decompilation of the GameCube title *Mario Superstar Baseball* (GYQE01).

## 1. GCC 2.6 / PowerPC PPC Behavior Patterns

### Global Address Re-loading
The compiler often re-loads the base address of a global variable (using `lis` and `addi`) even if that address is already in a nearby register. 
*   **The Trap**: Local pointers (e.g., `Batter* b = &g_Batter;`) often cause the compiler to "hold" the address in a single register, mismatching the original.
*   **The Pattern**: Use **direct global access** (e.g., `g_Batter.field = ...;`) in distinct logical blocks to trigger a fresh load.

### Structure Assignments and Update-Form Instructions
The binary frequently uses "load/store with update" instructions (`lfsu`, `stfsu`).
*   **The Pattern**: These are often generated by structure-level assignments:
    ```c
    g_Runners[0].position = g_Batter.batterPos; // Triggers stfsu patterns
    ```
*   **Point-by-Point**: Assigning individual fields (`p.x = b.x; p.z = b.z;`) usually fails to trigger the update-form instructions.

### Register Steering ("Anchoring")
Registers `r31` and `r30` are typically used for major object base pointers.
*   **The Pattern**: Define a local pointer **at the exact line** where the assembly first allocates the base register. Defining it at the top of a function often causes the compiler to use a temporary register instead.

### ROData Ordering
Floating-point constants (literals) are stored in the `.rodata` section in the **order they are first encountered** in the C code.
*   **The Problem**: If your code uses `1.0f` before `0.0f` but the original did the reverse, their labels (`lbl_3_rodata_...`) will mismatch.
*   **The Fix**: Order your references (or dummy references) to match the assembly's order.

### Float Constants: Use Literals, Not `extern lbl_3_rodata_*`
Compiler-generated constants must be written as literals (`100.0f`, `0.0f`, or `0.0` for a `.double`).
*   **The Problem**: Declaring them as `extern f32 lbl_3_rodata_XXXX` lets them alias memory, so MWCC schedules their loads later and the float registers/order mismatch (e.g. target loads the constant first into `f2`).
*   **The Fix**: Look up the value with `grep -A1 "^\.obj lbl_3_rodata_XXXX," build/GYQE01/game/asm/game/*.s` and use the literal. Matched fn_3_13D5E8, fn_3_13DA20, fn_3_B8574, fn_3_A372C, fn_3_E45A8, fn_3_19770, fn_3_C0F8C.

### Quick Fixes That Worked Repeatedly
*   **Register swaps between locals**: change local *declaration order* (MWCC assigns saved registers by declaration order); brute-force permutations if needed. Also controls stack slot order (first declared = highest address).
*   **Duplicated code in the target**: the original used a `static inline` helper (build flags are `-inline noauto`, so `inline` is required).
*   **`frsp` right after `sin`/`cos`**: cast the call, `(f32)cos(x)`.
*   **`mulli rX, rY, -1`**: write `x *= -1;` (not `x = -x` or `x = x * -1`).
*   **One extra `mr` before a loop**: the original used two pointer variables (`p = base; q = p;`).
*   **`lhz`/`lha` or `clrlwi`/`extsb` mismatches**: fix the field or parameter signedness/width in the header (check other users first).
*   **Negative or large relocation addends** (e.g. `lbz r4, -0x2a2(rX)` on `lbl_3_data_8338`): this is array indexing with a shifted index (`table[soundID - 0x151].volume` with 2-byte entries), or a field of a larger struct. Model it with types; never reproduce it with `(u8*)` arithmetic.
*   **Fields declared as scalars but indexed in asm** (e.g. `MiniGameStruct` wall-ball coins, `objects[40]`, `pendingPoints[4][10]`): the padding usually reveals the real array length; convert to arrays.
*   **Inline `srawi`/`xor`/`subf` absolute value**: use `__abs(x)`.
*   **`cntlzw` form flipped to the opposite compare**: `BOOL r = a >= b; return r == FALSE;` keeps the `cntlzw` instead of letting MWCC invert to `<`.
*   **Flag computed into the wrong register**: write `(x != 0)` inline at the use site rather than through a temp (fn_3_11A38C, fn_3_119CA8).
*   **Unrolled repetitive code**: try a plain `for` loop; MWCC unrolls it (fn_3_60768, fn_3_6AEE0).
*   **Literal exception**: occasionally only the `extern` rodata form matches (fn_3_70AEC needed `extern f32 lbl_3_rodata_1250` for 0.5). Try both.
*   **`lbz rX,off(rX); extsb rX,rX` straight into an arg register**: field is `s8` and callee param is `s32`. A `u8` field with an `(s8)` cast gives `lbz r0` + `extsb r3,r0` instead (fn_3_1158F8).
*   **Search loop returning index then `OSPanic`**: `for (u32 i = count; i > 0; i--) if (e[i-1].id == x) return i-1;` — `while (count--)` does not match (fn_3_D53C0, fn_3_F5E78).
*   **Extra loop-entry check (`cmpwi 0,N; bge`) missing**: loop counter must be `s32` (signed long), not `int`/`u32` (fn_3_1166CC).
*   **`bge`+`b` early exit on an s8 arg**: `if (a >= 15 || a < 0) return;` — separate ifs give `blt` (fn_3_14CB28; may also fix fn_3_14DC80).
*   **Locals 0x10 apart but only 12 bytes copied**: they are 16-byte structs (`VecXYZW`) (fn_3_105A10).
*   **Float `bge` without `cror`**: `if (!(d < min)) break;` rather than `d >= min` (fn_3_BBBC).
*   **Pointer param in r31 but target uses r29**: make the param `s32` and cast at use (fn_3_910F4).
*   **Several strength-reduced array pointers in a loop**: declare per-iteration pointer locals at the loop top (fn_3_63A38).
*   **`try_function.py` on MATCH prints an empty second-to-last line** — don't grep only its tail.
*   **Stop MWCC unrolling a constant-count loop**: `i = 0; do { ... a->entries[i] ...; i++; } while (i < N);` — `for`/`while` get fully unrolled (fn_3_1078F8, fn_3_109CE8).
*   **Saved register reused across a call**: reuse the parameter variable (loop counter = `idx` param in fn_3_C0C4C; `list` param reassigned with the result in fn_3_BA1A0).
*   **Float reg order after `fneg`+`fmuls` or `sin`/`cos`**: split into successive assignments to one local; store `sin`/`cos` into f32 locals and negate after (fn_3_F4C4C).
*   **`bnelr` leaving r3 untouched**: the original had no return on that path (fn_3_109CE8).
*   **Load scheduled from the global rather than a temp**: `global.field = table[x]; if (global.field ...)` (fn_3_10F5BC).
*   **Statics accessed through one base symbol**: model as a struct overlay on that symbol (fn_3_F0184, `StaC5Bss_AEE0`).
*   **Stubborn register/stack permutation**: try a `static inline` helper for the working pointer (out-param or getter) (fn_3_E698C, fn_3_E4BE8, fn_3_E67F4).
*   **Same loop at two sites, different regalloc**: shared inline; in a short+long pair, inline only into the longer one and write it directly in the short one (fn_3_146928; fn_3_8B804/8BDF4).
*   **`u8` field compared with `cmpwi`**: `(s32)field == 1` (fn_3_5CFD0).
*   **Float `!= 0` with swapped `fcmpu` operands**: `if (PSVECMag(v))` (truthiness) instead of `!= 0.0f`.
*   **Double `cntlzw`/`srwi`**: `return !!call();`.
*   **Non-unrolled countdown (`cmpwi`/`subi`/`bne`)**: `i = N; do { ... } while (i-- != 0);`.
*   **`addi`/`mr`/`stw` two-pointer prologue**: chained `p = *out = table->entries;` (fn_3_6424).
*   **Per-element pointer declared inside the loop body** fixes register order (fn_3_B3BD0, fn_3_11874C).
*   **CRC-style if/else sharing a shift**: separate `crc >>= 1; crc ^= 0x8408;` stops hoisting.
*   **Two `Mtx`/adjacent locals in swapped stack slots**: swap declaration order. For register swaps, brute-force declaration orders with itertools + `try_function.py`.
*   **Global byte read hoisted out of a loop**: read the global directly in the loop body, don't cache it in a local (fn_3_86DFC).
*   **`clrlwi`+`cmplwi 1` kept inside a loop on an s16**: `!(x == 0 || x == 1)`; a `(u16)x > 1` cast gets hoisted (fn_3_889FC).
*   **`addi rX,idx,5; slwi; add; lwz 4(r)` instead of folded displacement**: put the index in a local first (`slot = idx + 5; files[slot]`) (fn_3_90F48; may help fn_3_90AB0).
*   **`srwi` not `srawi` on a u8 `>> 1`**: `x / 2` or `(u32)x >> 1`.
*   **Float args loaded before pointer args**: the callee prototype has the floats first (fn_3_C3E94).
*   **Shared tail block placed before `return FALSE`**: `if (c) { switch {... case 3: goto done;} } else { done: ...; return TRUE; } return FALSE;` (fn_3_B254C).
*   **`slwi` without `clrlslwi` indexing by a u16**: `(&arr[idx])[1]` rather than `arr[idx + 1]` (fn_3_91B9C).
*   **`try_function.py` candidates**: omit the `// .text:` comment line (it duplicates); don't `git checkout` a file mid-iteration (wipes added includes).
*   **Block order from branch shape**: nest as `if (a >= 0) { if (!b) {...; return;} } else {...; return;}` instead of an if/else chain (fn_3_B6C9C); moving a local's declaration into the else block delays its initialiser (fn_3_E3668).
*   **Load of `next` before a trailing call**: `bone = bone->next; GXSetTevDirect(..)` in the body, not in the `for` increment (fn_3_EEE3C).
*   **Swapped `fcmpo` with `cror eq,gt,eq`**: `2.5 >= PSVECMag(&v)` instead of `PSVECMag(&v) <= 2.5` (fn_3_E28DC).
*   **Switch case source order** flips `beq`/`b` block order even for identical bodies (fn_3_E7A2C).
*   **Stray `extsh r3` before `bl`**: callee param is s16. `cmplwi` against 0 on an int field: field is u32. `li r0,-1` + `stb`: global is s8.
*   **`addi`+`mr` before a loop**: index with a per-iteration `T* t = &arr[i]` instead of `t++` (fn_3_13DEA4).
*   **`extsh` right after an s16-returning call**: store into an `s32` local, cast `(s16)` at use (fn_3_2B5C0).
*   **Pointer loaded into a temp then `mr r31`**: assign inside the first call's args, `fn(scene = lbl_803CC1B8, &d)` (fn_3_158FE4).
*   **`u8 += 34.0` vs `u8 = u8 + 34.0`** differ in `fadd` operand order; try both (fn_3_CED40).
*   **Field read scheduled before an earlier byte store through a global pointer**: read it into an `s32` local before the store (fn_3_160814).
*   **`beq body; b exit` tail**: one `if (!a || b) return;` (fn_3_15810C).
*   **Guard returns ending in `bne L; blr` / `bne L; b end`**: combine into one `if (a || b || c) return;`; separate ifs give `beqlr` (fn_3_14A070, fn_3_8B890).
*   **Flipped `bgt`/`ble` or `beqlr`/`bnelr` around two returns**: swap which branch holds the side-effect body / which return comes first (fn_3_61148, fn_3_12E084).
*   **Strided unrolled checks**: `for (i = 1; i < 15; i += 3) { a[i]; a[i+1]; }`, not `a[i*3+1]` (fn_3_12ED80).
*   **rep_1838.c duplicates**: compose the same-file helpers, e.g. `getComponentsFromRad(shortAngleToRad_Capped(ang), x, y)` (fn_3_9F9C8).
*   **Statement order changes regalloc even for independent globals** (fn_3_5C5C8).
*   **`MiniGameStruct* mg = &g_Minigame;`** at top hoists `lis`/`addi`; placed after a call it anchors r30 (fn_3_12E084, fn_3_12C74C).
*   **Scratch-register-only code**: brute-force the order of initializing assignments (fn_3_60D80). Declaration order *can* still matter: swapping `s32 row;`/`s32 sub;` took fn_3_8C104 from 76 to 7 diffs.
*   **Parameter that seems unused**: it may be passed straight through to a callee in `r3` (fn_3_5B380 → `fn_8004CA6C`).
*   **Float association**: `0.75f * ((d - lim) / 8.0f)` matched where every `* 0.125f` form swapped fregs (fn_3_D5494).
*   **`u8* p = bss->texData; p += off;`** as two statements gives `addi base,0x40; add off`; `&texData[off]` folds 0x40 into the index (fn_3_133200).
*   **Chained `a = b = K`** stores `b` first; use it to steer store order (fn_3_133200).
*   **Small int array of constants**: `for (i=0;i<4;i++) ids[i]=i+1;` matched; an initializer makes a rodata copy (fn_3_15AE34).
*   **Inlined sibling body**: `static inline` copy of the sibling plus a local `&g_d_GameSettings` used after it (fn_3_5D3FC); nested inlines each with their own `Vec center = {...}` reproduce duplicated rodata Vec copies (fn_3_135924).
*   **Debug no-ops like `if (i == N) i = N;` survive** into the binary (fn_3_105CDC).
*   **`u8 &= 0xFB`** gives `andi.`; `&= ~4` gives `rlwinm` (fn_3_D196C).
*   **u8 passed to several calls and compared with a u16**: declare the local `s32` (fn_3_158264).

*   **Code repeated across a sibling chain** (F1750/F3BB0/F3AE0): turn the matched sibling into a `static inline` and call it; fixes float load order. But a standalone function whose body is also inlined elsewhere must keep its own body (fn_3_F38D4/F37BC).
*   **Stack Vec passed as three float pointers**: one `Vec pos` with `&pos.x, &pos.y, &pos.z`, not three f32 locals (fn_3_C414C).
*   **Missing `frsp` after acos**: `(f32)acos(x)`.
*   **extsb'd index in a saved reg**: local is `s32 idx = obj->s8field`. `lbz r0; extsb` on byte data = `u8*` buffer read into `s8` temps.
*   **Avoid range-merge of compares**: compare the global directly (`g_GameLogic.gameStatus == 0x1C || == 0x1B || == 0x1D`), no u8 local (fn_3_12C3F0).
*   **`li -1; stb` then `cmpwi 1` without extsb**: field is s8.
*   **PSVECScale**: header prototype is `(src, f32, dst)`; call as `PSVECScale(src, k, dst)` for the real `(src, dst, scale)` registers.
*   **Callee reads an r4 the caller never sets**: pass the caller's own 2nd param through (fn_3_F1750 → fn_800B4A94).

*   **Matrix locals**: element-wise `m[0][0] = 0.5f; ...` gives `stfs` runs; a brace initializer emits rodata + word copies (fn_3_C9C94).
*   **`lbzx` into dest then `extsb rX,r0`**: wrap the read in a `static inline s8` getter (fn_3_C9B5C).
*   **Unroll-by-4 with `srwi.`/`andi.` remainder**: `s32` count, `while (count != 0) { *p++; count--; }`; a `u32` count unrolls by 8 with `cmplwi` (fn_3_15FA58).
*   **Only `li` regs swapped behind independent global stores**: brute-force the store order (fn_3_15FA58).
*   **`lwzx rX,rX,rY` against an early-loaded table**: `T* e = &base[table[idx]];` at the declaration (fn_3_5518).
*   **`clrlwi.` after a byte store then a test**: store to the global and re-read it (`g.f = x; if (g.f == 0)`) (fn_3_1F350, fn_3_DC5A4).
*   **Shared else-body placed last**: `else if (a != b) { if (c) ... else ... } else { shared }` (fn_3_20064).
*   **Two sequential loops**: separate counters `i`/`j` + decl-order brute force (fn_3_1637EC). `u8` locals compared with `cmpw` → `s32` (fn_3_163A7C).
*   **Per-branch pointer on the first line of the branch** avoids strength reduction and an extra saved reg (fn_3_6BEA4).
*   **`slwi`/`add`/`mulli 0xb` for `(x/2)*22 + (x%2)*11`**: write `(x % 2 + (x / 2) * 2) * 11` (fn_3_53E0).
*   **Re-added `lbzx` index**: index the global array directly, no cached row pointer (fn_3_B5090).

*   **Range merge of `==1||==2||==3` on a field**: read the s16 global field at every compare instead of caching in an s32 local (fn_3_62B50). Retry fn_3_B7CDC/B7C2C this way.
*   **Keep `+5` out of the displacement**: `lbl_80371C30[i + (scene->unkIndex + 5)]` (fn_3_91D1C).
*   **`li` arg setup scheduling**: `static inline` helper for an arg expression repeated across two calls (fn_3_94760).
*   **`lbz; extsb.; extsb`**: the field is `s8`; casting a `u8` field to `(s8)` reuses one extsb (fn_3_65FE0).
*   **Float-constant load order**: `f32 half = 0.5f;` local fixed it where literal and extern both failed (fn_3_14D318).
*   **Base held in r3 throughout**: `Scores* s = &g_Scores;` at top (fn_3_22ABC). **Anchor in r31**: assign after the first store, `x = 1; settings = &g;` (fn_3_972C8).
*   **Stray `b` before a shared tail**: `else if (id != 3 || cond) return;` (fn_3_128A38).
*   **rep_3310 "0x34 folded" family — possible fix**: take `&entries[i].unk34` as a sub-object pointer (cast or call arg) to get `addi rX,idx*0x90,0x34; add` (fn_3_1189C8, fn_3_11AB2C). Retry 119EE0/119E30/11881C/11897C/1194AC.

*   **Struct assign from a global Vec** (`obj->pos = gVec`) gives `lwz/stw`; per-component gives `lfsu/lfs/stfs` (fn_3_136CF4).
*   **`fadds f2,f0,f0`**: write `x + x`, not `2.0f * x` (fn_3_1F1CC).
*   **Float consts in swapped regs**: check source order of the constants (`minX = 10000; maxX = -10000;`); r3/r4 swap fixed by declaring `s32 t` before `u16 count` (fn_3_E4A38).
*   **Value used unclamped in one branch and clamped later** (target keeps a copy): put the unclamped use in a `static inline` that recomputes it (fn_3_1382E0).
*   **`InputStruct* in = &g_Controls[...]`** local fixes `lwz r4 / addi r0` order (fn_3_835B0).
*   **Inlined spawnCharacterParticles**: declare `s8 type;` after the task pointer so the pointer keeps r31 (fn_3_166FCC).
*   **`bne L; b end` after a byte check**: index the array directly in the test and store instead of caching `&arr[idx]` (fn_3_8BA60).
*   **Inlined switch returning a value with no default** leaves the result reg unset; a static inline copy reproduces it (fn_3_16058, 161C0, 16328).
*   **try_function.py restores only the function body**: helper inlines from a failed candidate stay in the file; reset the file between candidates.

*   **`subfic/cntlzw/srwi/or.` for adjacent-constant compares**: bitwise or, `(x == 11) | (x == 12)` (fn_3_C625C) — another range-merge workaround.
*   **`addi rX,idx,1; slwi; lwzx`** instead of folded `lwz 0x8(r)`: `arr[(s32)(u16field + 1)]` (fn_3_912B4).
*   **Every switch case sets a flag FALSE**: `goto` one shared `flag = FALSE;` label (fn_3_C9878). Writing `set->entries[view][i].val[flag]` directly (no element ptr) gave the target's two parallel pointers.
*   **Repeated GXPosition3f32/GXColor1u32 vertex blocks**: a plain 4-iteration `for` loop; MWCC unrolls to the `lfsu` form (fn_3_1480E0).
*   **Byte field loaded before an if/else computing a delta**: read it above (`alpha = node->color[3];`), add after (`alpha += da;`) (fn_3_14CBB4).
*   **`rand() % range - range / 2`**: keep `range / 2` inline, no `half` local (fn_3_13DFBC).
*   **Global in a saved reg but a local pointer mismatches**: use the global directly; keep a pointer only for the other base (fn_3_1589C4).

*   **Independent stores to different globals get reordered**: source order may be the reverse of binary order — try swapping (fn_3_B4124, fn_3_B5694).
*   **Inline init helper taking its float constants and count as args** reproduces runtime `(f32)n` and rodata/`lis` order; read the count back through the struct (`p->unk20 = n; 1.0f / p->unk20`) to block folding (fn_3_CC438).
*   **Object ptr into r31**: declare the param as the first-member type (`Control*`) and cast to the container in a local (fn_3_D00D0).
*   **`!x` vs `x == 0` as a call arg** schedule `addi r4,r1,X` differently (fn_3_BC888).
*   **u16 counter saturating at 0xFFFE**: the field must be `u16`; `(u16)` cast of an s16 field still emits `lha`+`clrlwi` (fn_3_B482C).
*   **Callee gets r3 from a bare `lis`** (no `addi`): it takes no args (fn_3_B8298).
*   **s16-returning call results in add/sub chains**: `s32` locals (fn_3_6AF9C, fn_3_57A14).
*   **ctr loop over a byte array in a global**: index the global directly; cached `MiniGameStruct*` gives `lbzx` (fn_3_111738). `if (n != 0) { for ... }` reproduces an extra `cmpwi; beq` before `mtctr` (fn_3_90DD8).

*   **`bge L; b end` tail**: `if (x >= N) goto remove;` inside the nested block, `return;` at its end, `remove:` after the outer if (fn_3_91E4C, fn_3_15F088).

*   **Byte read at offset**: `u8* p = bss->arr; p += off; v = *p;` gives `addi base,0x40; lbzx` (fn_3_132EDC).
*   **`lbzu` counter**: `if (++counter >= 5)` on a plain extern s8 (fn_3_1666B0).
*   **Branchless or-chain with `>=`**: `(a >= 2) | (x == 11) | (x == 12)` gives `subfc/adde` + `cntlzw` + `or.` (fn_3_B91C8).

*   **Global address recomputed per block but kept live across branches**: two local pointers to the same global (fn_3_ED818).
*   **Stray extsb on a byte field**: anonymous-union `s8` view (fn_3_DCA68) or plain `(s8)` cast where target has `lbz r0; extsb` (fn_3_795A8).
*   **u8 copy do-while bound**: compare through the global (`g_Minigame.n`), not `mg->n` (fn_3_1079C8).
*   **Stub signatures matter for callers**: giving stub `fn_3_A46A0` its real `s32 idx` param also matched fn_3_A1F3C.

*   **Constant-first index sums**: `arr[1 + a + b]` gives `add; addi; slwi; lwzx`; `a + b + 1` reassociates the constant onto `b` (fn_3_15A244).
*   **CR-bit flag words** (mfcr/rlwinm/rlwimi chain): build over separate statements, `f = (x < lo) | ((x > hi) << 1); f |= (y < lo) << 2; ...` (fn_3_C2AA0).
*   **cmplwi on a masked u8**: `(u32)(acc & 3) == 1` (fn_3_C2AA0).
*   **Split pointer initialisers**: `T* a; U* b; b = ...; a = ...;` in the target's computation order fixed an r30/r31 swap (fn_3_7DB30).
*   **Right after `g_pCamera = (Camera*)&g_Camera;`** write through `g_pCamera->` so stores alias and force the target's `lwz` reload (fn_3_1CCC8).
*   **`f32 half = 0.5f; w * half`** puts the variable operand first in `fmuls`; a literal goes first (fn_3_C2AA0).
*   **Dead `b end` after `b check`**: `if (cond) { ...; goto check; } return;`. `bge L; b end` before a copy: `if (!visible || x < 0.1f) return;` (fn_3_16D5E4).
*   **Callee reads an f3 the caller never sets**: the caller's own 3rd float param is passed through; check its callers for the real signature (fn_3_8FF5C / fn_3_1650C).
*   **GX enums**: blend dst 1 is GX_BL_ONE; ChanCtrl amb src 1 is GX_SRC_VTX — check the `li` values.
*   **Permutation brute force**: try_function.py builds in ~0.5 s; permute lines between `//PERM_BEGIN`/`//PERM_END` markers with `tools/brute.py <src> <fn> <template.c>` (matched fn_3_7AB78 in seconds). Don't wait on it with `pgrep -f <name>` (matches the loop itself).

*   **Global's `addi` lands in r4 not r3 before a `bl`**: the callee takes a parameter, e.g. `fn_80033620(arg)` (fn_3_14A188).
*   **fmuls operand order / early constant load before an array-initializer copy**: initialise scalars in their declarations before the array (`f32 half = 0.5f; f32 w = node->scaleX * half;`) (fn_3_1517D0).
*   **`x % 3 != 0` merged with an earlier `x % 3 != 2`**: write bare `if (x % 3)` (fn_3_12F424).
*   **`clrlwi`/`stb`/`extsb.` order around an increment**: `g.f++; if ((s8)g.f >= n)` not `(s8)++g.f >= n` (fn_3_B3448).
*   **Mixed `bne L` then `beq L` guards**: two separate `if (...) return;`, not one `||` (fn_3_11A92C).
*   **Args/stores scheduled wrong around calls**: hoist nested calls into a local (`cam = fn_80052734(fn_8005268C());`); store a call result via a temp so the target ptr is re-read (fn_3_E5A84).
*   **Store order across calls**: a struct-field store may need to move past a later call (fn_3_14EAF4); statement-permutation brute force (tools/brute.py) solved fn_3_8C2DC, fn_3_11A92C, fn_3_151BAC.
*   **`lwzu` on a global's first field** can come out naturally (`(f32)g.unk0` then other `g.` reads, fn_3_1534C0) — try once before calling it unfixable.
*   **`(f32)` of a u8 with signed `xoris` conversion**: `(s32)(u8)(v >> 8)`; plain u8 gives the unsigned magic constant (fn_3_8C2DC).

*   **Same body inlined in a same-file caller** (CC1D4 in CB8A8, D2220 in D36B0, D4CA4 in D4E00): `static inline` copy for the caller; keep the standalone function's own body.
*   **Weighted-random pickers inline `RandomInt_Game`**: a `static inline` copy of the rep_1838 body (fn_3_9E368, fn_3_9E5A0).
*   **Clamp in r0 vs r3/r4**: split it, `x = obj->alpha; x -= 1.7f;` / `a = p->unk43; a -= 8; if (a < 0) a = 0;`.
*   **`acos(...) / 2.0`** matched where `* 0.5` and `0.5 *` swapped fmul operands.
*   **Stubborn fmuls operand swap**: store an intermediate first (`step = (b-a)/5.0f` local) or compute all trig into locals before any struct store (stfsu pattern, fn_3_E3044).
*   **File-static block off one base, scalar fields**: overlay struct + local `T* bss = &lbl_X;` matched (fn_3_E1DB8, fn_3_C937C, fn_3_142088); separate externs like lbl_3_bss_B7C1 can stay.
*   **`lfsx`/unfolded base**: `p = arr; p += idx; x = *p;` stops folding the field offset into the displacement.
*   **ACTSetAnimation** takes `(Actor*, ANIMBank*, char*, u16, f32 unk, f32 time)`: callers pass a hidden 0.0f in f1, time in f2 (fixing the prototype matched fn_3_B97DC; may unblock fn_3_168414, 168A6C, BF238, F9E78).
*   **Per-function rodata table**: `static const f32 x[3] = {...}` inside the function (fn_3_E29B4).

### Known Unfixable Patterns (don't spend attempts)
*   **Unrolled g_Runners loops with regs off-by-one in allocation order** (fn_3_88C24, fn_3_8A618) and **`lis r3/r4` swap after PSVECScale** (fn_3_E4658, E4760, E48D0): no loop/inline/reorder form fixed them.
*   **Dead double `b end; b end` after a 2-case switch dispatch** (`cmpwi 1; beq; bge; cmpwi 0; bge; b; b`): default/return/case-order/local tried. Seen in 22 unmatched fns incl. fn_3_21C90, fn_3_21DE4, fn_3_3904, fn_3_39858, fn_3_45394, fn_3_BD504, fn_3_E7B20, fn_3_EC014, fn_3_1133C4, fn_3_15FB84.
*   **`lwzu` on a global counter** (`lis; lwzu r3,sym+0x8@l(r4); stw r3,0(r4)`): no struct/union/pointer form reproduces it; likely a separate static in the original (fn_3_16943C).
*   **File-static bss block off one base with array members** (rep_18E8 lbl_3_bss_17F8..1900): overlay struct works for scalars (sta_c0 9F38) but array sub-bases get folded; real `static` defs don't help under `-pool off` (fn_3_A2B6C, fn_3_A2C9C; also fn_3_EECF4, fn_3_1048E0).
*   **Same-file static data off one base register** (`addi r4,r31,0x4f44` from `&lbl_3_data_1C0A8`): extern symbols reload `lis`/`addi` per use (fn_3_1048E0).
*   **Adjacent-constant compares merged into a range check** (`== 9 || == 10` → `subi`/`cmplwi 1`) when the target keeps them separate (fn_3_B7CDC, fn_3_B7C2C). **Possible workaround** (worked for fn_3_5C418): compare as unsigned, `(u32)x == 1 || (u32)x == 2`, and write intended ranges as `(u8)(x - 0x13) <= 3`. Retry B7CDC/B7C2C with this.
*   **Field offset `0x34` folded into the index of an `lwzx`** instead of the base (rep_3310: fn_3_119EE0, fn_3_119E30, fn_3_11881C, fn_3_11897C, fn_3_1194AC).
*   **Nested-struct field load folded** (`addi r3,r31,0x10; lwz r3,0xc(r3)` → `lwz 0x1c(r31)`) (fn_3_A32B8).
*   **Same callee with differing arg counts in one file** (`fn_800216F8`: 2 args in fn_3_90860/90928/90A18, 3 in fn_3_90C14) — one prototype can't satisfy both.

### Unprototyped Calls (`fn_80034E20`)
`fn_80034E20` is declared without a prototype (`void fn_80034E20();`), so call it with the arguments the target actually passes. Most callers pass two (no `r5` setup); adding a third `&lbl_803CC1B8` argument was the cause of several "NONMATCHING: 2-arg call" notes.

## 2. Tooling Ecosystem

### `tools/kappa_context.py`
A comprehensive context gatherer.
*   **Usage**: `python3 tools/kappa_context.py --function atBat_batter`
*   **Output**: Standardized ASM, resolved bl signatures, and data symbol locations. Use this to seed any new decompilation task.

An instruction-level analyzer for iterative refinement.
*   **Usage**: `python3 tools/feedback_diff.py game/game/game_batter atBat_batter`
*   **Focus**: Identifies **Missing**, **Extra**, and **Mismatched** operands (offsets/constants) while ignoring register swaps in the early stages.

Always use feedback_diff.py to compare the decompiled code to the original assembly.

### `tools/decomp_helper.py`
Simplifies the retrieval of ASM for a given unit and symbol.

## 3. Best Practices for Match %
1.  **Prioritize Operands**: Fix offsets (`0x8(r3)`) and constants (`1.0f`) first.
2.  **Match Instruction Mnemonics**: Ensure `lwz` isn't compiled as `lhz` (check your struct types!).
3.  **Instruction Order**: If instructions are identical but out of order, check for sub-expression dependencies.
4.  **Casting**: Use explicit casts to match sign-extension instructions (`extsh`, `extsb`).

## 4. Struct Nuances
Many structs in this project use explicit padding or fixed offsets. Always refer to `include/game/UnknownHomes_Game.h` for current layout.
*   **Batter**: Base Address typically in `r31`.
*   **Pitcher**: Base Address typically in `r3`.
*   **Runners**: Array access often uses `r3` + index offset.
